Changing charts

Matthew Litwin 2026-06-23

A vector or covector at a point is the same object in either chart; only its components change. This page does the bookkeeping.

The Jacobian

A coordinate basis vector ∂μ~\partial_{\tilde\mu}∂μ~​​ at a point is the derivation ∂/∂x~μ\partial/\partial \tilde{x}^\mu∂/∂x~μ. By the chain rule applied to any smooth function fff:

∂θ~=∂θ+αsin⁡θ~ ∂φ,∂φ~=∂φ,\partial_{\tilde\theta} = \partial_\theta + \alpha\sin\tilde\theta\, \partial_\varphi, \qquad \partial_{\tilde\varphi} = \partial_\varphi, ∂θ~​=∂θ​+αsinθ~∂φ​,∂φ~​​=∂φ​,

In matrix form, with the basis elements collected in a row vector (so that each new basis vector picks up a column of the matrix):

(∂θ~∂φ~)=(∂θ∂φ)J−1.\begin{pmatrix} \partial_{\tilde\theta} & \partial_{\tilde\varphi} \end{pmatrix} = \begin{pmatrix} \partial_\theta & \partial_\varphi \end{pmatrix} J^{-1}. (∂θ~​​∂φ~​​​)=(∂θ​​∂φ​​)J−1.

The basis transforms with the inverse Jacobian. This is the defining property of a covariant index — moving with the basis, opposite to how vector components move.

Components transform with JJJ

A tangent vector v\tens{v}v has components vμv^\muvμ in the standard chart and v~μ~\tilde v^{\tilde\mu}v~μ~​ in the skew chart. The intrinsic identity

v=vθ ∂θ+vφ ∂φ=v~θ~ ∂θ~+v~φ~ ∂φ~\tens{v} = v^\theta\, \partial_\theta + v^\varphi\, \partial_\varphi = \tilde v^{\tilde\theta}\, \partial_{\tilde\theta} + \tilde v^{\tilde\varphi}\, \partial_{\tilde\varphi} v=vθ∂θ​+vφ∂φ​=v~θ~∂θ~​+v~φ~​∂φ~​​

This is the covariant rule — index down.

Derivation

The derivation viewpoint generalizes: a derivation of AAA (with values in AAA) is a vector field; the Lie bracket of vector fields is the commutator of derivations.
