Integration on manifolds works on top-degree forms over oriented manifolds. The capstone is Stokes’s theorem, which unifies most of the classical integration theorems of vector calculus — the fundamental theorem of calculus, Green’s, Gauss’s, the classical Stokes — into a single statement about ∫dω=∫∂ω\int d\omega = \int_\partial \omega∫dω=∫∂​ω.

Where this lands in GR.
