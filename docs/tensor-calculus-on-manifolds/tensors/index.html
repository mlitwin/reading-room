Tensors

Matthew Litwin 2026-06-23

A tensor is a multilinear map that takes some vectors and some and returns a real number. Physicists call it an (r,s)(r, s)(r,s)-tensor with rrr upper and sss lower indices. Mathematicians call it an element of TpM⊗r⊗Tp∗M⊗sT_p M^{\otimes r} \otimes T^*_p M^{\otimes s}Tp​M⊗r⊗Tp∗​M⊗s. The two are the same object.

  2. Coordinate components: the transformation law, summation, the tensoriality test.
  3. Two languages: index and coordinate-free notation side by side; kkk-forms and symmetric tensors.
