Reference Grammar

A complete reference grammar for the Latin texts here. It began as Allen and Greenough's New Latin Grammar for Schools and Colleges, and keeps its section numbering (§), so a citation like “§ 419” links straight here; corrections and additions are this site’s own. For the compact guide to pronunciation and the terms used by the reader's word popovers, see the Latin Reader's Guide.
